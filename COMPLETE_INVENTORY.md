## 🚀 Quick Start Commands

### One-Line Setup (Web Version)
```bash
pip install -r requirements.txt && python mario_india_web.py
```
Then open: http://localhost:5000

### One-Line Setup (Desktop Version)
```bash
pip install -r requirements.txt && python mario_india_game_enhanced.py
```

### Separate Commands (If One-Line Doesn't Work)
```bash
# Install dependencies
pip install -r requirements.txt

# Run web version
python mario_india_web.py

# OR run desktop version
python mario_india_game_enhanced.py
```
